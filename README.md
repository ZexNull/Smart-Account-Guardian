# 👁️‍🗨️ Smart Account Guardian (نظام حارس الحساب الذكي)

An advanced **Context-Aware Security Architecture** that monitors input patterns to mitigate brute-force risks instantly.

## 📝 ملخص المشروع (Abstract)
**المشكلة:** تعاني أنظمة تسجيل الدخول التقليدية من ثغرة "العمى الرقمي"، حيث تمنح المخترقين محاولات تخمين مجانية قبل قفل الحساب، وفي نفس الوقت تعاقب المستخدم البشري الحقيقي بإغلاق حسابه لمجرد خطأ إملائي بسيط.

**الهدف:** يهدف هذا المشروع إلى ابتكار طبقة حماية ديناميكية ذكية (Context-Aware) تفرّق بذكاء بين نية المهاجم السيبراني وبين الخطأ العفوي للمستخدم البشري الحقيقي.

**المنهجية:** تم بناء نموذج تطبيقي للنظام باستخدام لغة **Python** وإطار عمل **Streamlit** بالاعتماد على خوارزمية قياس المسافة النصية ومطابقة الأنماط الحرفية (`difflib`) لتحليل الكلمات المدخلة فورياً. تم ضبط عتبة الحظر الأمني عند **40%**؛ فإذا كانت نسبة المدخل عشوائية تماماً (أقل من 40%) يقوم بـ **الحظر الفوري وقفل الخدمة من المحاولة الأولى**، أما إذا كان المدخل قريباً يتعامل معه كخطأ بشري طبيعي ويمنحه عداداً مرناً مكوناً من 5 فرص.
